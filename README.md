I developed a machine learning–based **Fake Review Detection** system to classify fraudulent and genuine reviews using natural language processing techniques. After performing text preprocessing and feature extraction, I trained multiple models including Logistic Regression (88.28%), Decision Tree (75.96%), Random Forest (85.59%), K-Nearest Neighbors (50.18%), Multinomial Naive Bayes (86.48%), and Support Vector Machine (89.78%). Among all models, Support Vector Machine achieved the highest accuracy, demonstrating strong performance in handling high-dimensional text data. Logistic Regression and Naive Bayes also performed well, indicating the effectiveness of linear and probabilistic models for text classification. The project involved comparative analysis of six algorithms to identify the most reliable approach for detecting fake reviews.
